# Ridge Regression and Multicollinearity

## Project Overview

This project investigates Ordinary Least Squares (OLS) regression, multicollinearity, and Ridge Regression using the Real Estate Valuation dataset.

The project compares different numerical approaches for solving OLS and examines how multicollinearity affects regression coefficient stability.

## Project Objectives

1. Implement OLS using the normal equations.
2. Solve OLS using QR decomposition.
3. Solve OLS using Singular Value Decomposition (SVD).
4. Compare the numerical performance of the three approaches.
5. Investigate multicollinearity using condition numbers and Variance Inflation Factors (VIF).
6. Implement Ridge Regression.
7. Study the Ridge Trace.
8. Select the regularization parameter using k-fold cross-validation.

## Dataset

Real Estate Valuation dataset from the UCI Machine Learning Repository.
